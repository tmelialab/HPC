# Genome Assembly and Annotation Pipeline Scripts - Code Details

This directory contains the scripts used for the genome assembly, annotation, and structural variation analysis pipeline for *Acacia crassicarpa*. The scripts are numbered sequentially to reflect the order of execution. Below is a detailed breakdown of the internal code mechanics of each script.

## English Version

### Data Acquisition
*   **`00_download_sra_reads.sh`**: 
    *   **Code Explanation**: This is an SBATCH script allocating 64 CPUs, 128GB memory, and 24 hours of runtime. It first activates the `training_qc` conda environment. Then, it utilizes a `while read` loop to iterate through lines in `sra_dump.txt`. For each line (an SRA ID), it executes `fasterq-dump "$srr" --split-files --threads 64` to download the sequence reads and split them into paired FASTQ files using 64 threads.

### Repeat Identification and Masking
*   **`01_build_repeatmodeler_db.sh`**: 
    *   **Code Explanation**: Allocates basic resources (4 CPUs, 16G RAM) on the cluster. Activates the `repeats` conda environment. Runs the command `BuildDatabase -name acacia_db -engine ncbi acacia_final.fasta`. This command takes the raw assembly (`acacia_final.fasta`) and builds a BLAST/NCBI formatted search database named `acacia_db`, which is required for the subsequent RepeatModeler run.
*   **`02_run_repeatmodeler.sh`**: 
    *   **Code Explanation**: Allocates 64 CPUs and 128G RAM. Activates the `repeats` conda environment. Executes `RepeatModeler -database acacia_db -pa 62 -LTRStruct`. This utilizes 62 parallel workers (`-pa 62`) and the LTR structural discovery pipeline (`-LTRStruct`) to find novel transposable elements and repeat families in the `acacia_db` database. The script also mentions that the command auto-resumes from a checkpoint (`RM_*/` folder) if it is re-submitted.
*   **`03_run_repeatmasker.sh`**: 
    *   **Code Explanation**: Activates the `repeats` conda environment. Executes `RepeatMasker -pa 62 -lib acacia_db-families.fa -gff -xsmall acacia_final.fasta`. This uses the custom repeat library (`acacia_db-families.fa`) generated by RepeatModeler to mask the genome. The `-xsmall` flag indicates "soft-masking", meaning repetitive bases are converted to lowercase letters rather than replaced by 'N's. It outputs a GFF file of the repeat coordinates.

### Structural Gene Annotation
*   **`04_align_rnaseq_star.sh`**: 
    *   **Code Explanation**: Activates `training_qc`. Sets the open-file limit via `ulimit -n 65535` to prevent errors during BAM sorting. It runs in three steps:
        1.  `STAR --runMode genomeGenerate`: Builds a STAR genome index using the soft-masked genome (`acacia_final.fasta.masked`) with `--genomeSAindexNbases 13` (optimized for an ~800Mb genome).
        2.  Aligns paired-end reads (SRR25080411, SRR25080412, SRR25816559) utilizing `STAR --readFilesIn` and outputs sorted BAM files (`--outSAMtype BAM SortedByCoordinate`).
        3.  Aligns single-end reads (SRR1168433) using the same methodology.
*   **`05_run_braker3.sh`**: 
    *   **Code Explanation**: Activates `training_qc` and exports `GENEMARK_PATH`. It collects the output BAM files from the STAR alignment into a comma-separated variable `$BAMS`. It then executes `braker.pl` with:
        *   `--genome=acacia_final.fasta.masked`: The soft-masked assembly.
        *   `--bam=$BAMS`: RNA-seq evidence for gene structures.
        *   `--prot_seq=Viridiplantae.fa`: Homology evidence from a plant protein database.
        *   `--softmasking`: Tells BRAKER to respect the lowercase soft-masked bases.
        This runs the comprehensive BRAKER3 pipeline (GeneMark-ETP and Augustus) to predict genes accurately.

### Functional Annotation
*   **`06_run_interproscan_summary.slurm`**: 
    *   **Code Explanation**: An SBATCH script to functionally annotate the predicted proteins. 
        *   **Step 1**: Runs `interproscan.sh` on the BRAKER output (`augustus.hints.aa.noStop`) with TSV format, GO terms, and pathway lookups enabled. It uses multiple databases: Pfam, SMART, ProSiteProfiles, ProSitePatterns, and SUPERFAMILY.
        *   **Step 2**: Employs standard Unix tools (`grep`, `awk`, `cut`, `sort`, `uniq`) to parse the resulting TSV file. It calculates the total number of proteins, those with hits, and those with GO terms. It extracts the top 20 Pfam domains and writes a summary report to `interproscan_summary.txt`.

### Comparative Genomics
*   **`07_run_syri_sv_analysis.sh`**: 
    *   **Code Explanation**: Activates the `syri_env` conda environment. It performs a multi-step pipeline:
        1.  Runs `minimap2 -ax asm5 --eqx` to align the query assembly to the reference assembly, generating a BAM file.
        2.  Uses an inline `awk` script alongside `samtools` to identify and filter the best 1-to-1 chromosomal matches by summing up matched bases (`refbp`) from the CIGAR string.
        3.  Extracts and normalizes the FASTA sequences for these specific paired chromosomes using `samtools faidx`.
        4.  Re-aligns the normalized sequences and runs `syri` using an inline Python wrapper script (manipulating `sys.argv`) to identify structural variants (synteny, inversions, translocations).
        5.  Passes the `syri.out` file to `plotsr` to generate a PDF visual comparison (`acacia_comparison_plotsr.pdf`).

### Utility Scripts
*   **`utils_make_genome_annotation_tsv.py`**: 
    *   **Code Explanation**: Currently an empty file (0 bytes), likely intended to be populated later with logic to convert the final GFF3 annotation into a streamlined TSV summary format.

## Versi Indonesia (Indonesian Version)

### Akuisisi Data
*   **`00_download_sra_reads.sh`**: 
    *   **Penjelasan Kode**: Skrip SBATCH ini mengalokasikan 64 CPU, 128GB RAM, dan waktu 24 jam. Pertama, skrip mengaktifkan lingkungan conda `training_qc`. Kemudian, menggunakan loop `while read` untuk membaca setiap baris dalam file `sra_dump.txt`. Untuk setiap SRA ID, skrip menjalankan perintah `fasterq-dump "$srr" --split-files --threads 64` untuk mengunduh dan memecah *reads* sekuensing menjadi file FASTQ *paired-end* dengan 64 thread.

### Identifikasi dan Masking Sekuen Berulang
*   **`01_build_repeatmodeler_db.sh`**: 
    *   **Penjelasan Kode**: Mengalokasikan resource dasar. Mengaktifkan lingkungan conda `repeats`. Menjalankan `BuildDatabase -name acacia_db -engine ncbi acacia_final.fasta`. Perintah ini mengubah file FASTA *assembly* menjadi format database pencarian yang kompatibel dengan NCBI BLAST untuk digunakan oleh RepeatModeler.
*   **`02_run_repeatmodeler.sh`**: 
    *   **Penjelasan Kode**: Mengaktifkan conda `repeats`. Menjalankan `RepeatModeler -database acacia_db -pa 62 -LTRStruct`. Perintah ini menggunakan 62 pekerja paralel dan mengaktifkan deteksi LTR (Long Terminal Repeat) untuk menemukan keluarga sekuen berulang (*repeats*) baru secara *de novo*. Jika waktu habis, skrip ini dapat dilanjutkan (resume) otomatis dari folder `RM_*/`.
*   **`03_run_repeatmasker.sh`**: 
    *   **Penjelasan Kode**: Mengaktifkan conda `repeats`. Menjalankan `RepeatMasker -pa 62 -lib acacia_db-families.fa -gff -xsmall acacia_final.fasta`. Memanfaatkan pustaka referensi yang dihasilkan oleh RepeatModeler untuk menutupi (masking) sekuen berulang pada genom. Bendera `-xsmall` melakukan *soft-masking* (mengubah huruf kapital menjadi huruf kecil untuk basa *repeats*), bukan *hard-masking* (huruf 'N'). Skrip ini juga menghasilkan file koordinat GFF.

### Anotasi Gen Struktural
*   **`04_align_rnaseq_star.sh`**: 
    *   **Penjelasan Kode**: Mengaktifkan `training_qc` dan meningkatkan batas *open files* (`ulimit -n 65535`). Prosesnya terbagi tiga:
        1.  `STAR --runMode genomeGenerate`: Membuat indeks genom menggunakan genom yang telah di-*soft-masking*, dengan parameter `--genomeSAindexNbases 13`.
        2.  Melakukan alignment pada *reads paired-end* ke genom menggunakan `STAR --readFilesIn` dan menghasilkan file BAM yang sudah diurutkan (sorted).
        3.  Melakukan alignment pada *reads single-end* dengan metode yang sama.
*   **`05_run_braker3.sh`**: 
    *   **Penjelasan Kode**: Menetapkan `GENEMARK_PATH` dan mengumpulkan seluruh file BAM RNA-seq ke dalam variabel `$BAMS`. Selanjutnya menjalankan `braker.pl` menggunakan genom yang di-*soft-masking*, bukti RNA-seq (`--bam`), dan bukti homologi protein (`--prot_seq=Viridiplantae.fa`). Parameter `--softmasking` diaktifkan agar BRAKER mendeteksi huruf kecil dari proses RepeatMasker.

### Anotasi Fungsional
*   **`06_run_interproscan_summary.slurm`**: 
    *   **Penjelasan Kode**: Skrip SBATCH ini melakukan dua tahap utama:
        1.  Menjalankan `interproscan.sh` pada hasil protein dari BRAKER (`augustus.hints.aa.noStop`). Proses ini menelusuri database seperti Pfam, SMART, dan SUPERFAMILY, serta mencari istilah GO (Gene Ontology).
        2.  Memanfaatkan perintah Unix dasar seperti `grep`, `awk`, dan `sort` untuk membaca output TSV, menghitung statistik dasar (total protein, total beranotasi), mencari 20 domain Pfam terbanyak, lalu menulis laporan ke `interproscan_summary.txt`.

### Genomika Komparatif
*   **`07_run_syri_sv_analysis.sh`**: 
    *   **Penjelasan Kode**: Mengaktifkan lingkungan conda `syri_env` dan mengeksekusi pipeline komparatif:
        1.  Menjalankan `minimap2` untuk melakukan *alignment* genom secara utuh antara referensi dan *query*, menghasilkan file BAM.
        2.  Menggunakan skrip `awk` sebaris (inline) untuk mengekstrak dan memilih pasangan kromosom terbaik yang memiliki perbandingan 1:1.
        3.  Mengekstrak urutan sekuens FASTA dari kromosom yang cocok menggunakan `samtools faidx` dan menormalisasinya.
        4.  Menjalankan program `syri` melalui *wrapper* Python untuk menemukan variasi struktural.
        5.  Mengeksekusi `plotsr` pada file hasil `syri.out` untuk membuat visualisasi PDF komparasi genom (`acacia_comparison_plotsr.pdf`).

### Skrip Utilitas
*   **`utils_make_genome_annotation_tsv.py`**: 
    *   **Penjelasan Kode**: Saat ini merupakan file kosong (0 byte). Diperkirakan file ini adalah tempat (placeholder) untuk *script* Python di masa depan yang bertugas memformat output anotasi akhir (GFF3) menjadi tabel TSV yang mudah dibaca.
